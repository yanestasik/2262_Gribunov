### Задание 1 **(2)**
*Рассмотрим следующую программу.*
```
d = {'sep': ',' , 'end': '\n'}
l = ['Утопия', 14, 'Вселенная', 25]
print (l, d)
print (*l, d)
print (*l, *d)
print (*l, **d)
```
*Объясните результаты ее работы.*

*При устном ответе на вопросы вам потребуется рассказать, что такое "Утопия 14" и "Вселенная 25".*

**Решение**

```python
d = {'sep': ',', 'end': '\n'}
l = ['Утопия', 14, 'Вселенная', 25]

print(l, d)
print(*l, d)
print(*l, *d)
print(*l, **d)
```

Вывод программы.

```text
['Утопия', 14, 'Вселенная', 25] {'sep': ',', 'end': '\n'}
Утопия 14 Вселенная 25 {'sep': ',', 'end': '\n'}
Утопия 14 Вселенная 25 sep end
Утопия,14,Вселенная,25
```

1. `print(l, d)` печатает список и словарь целиком. Это два аргумента, между ними ставится пробел.
2. `print(*l, d)` передаёт элементы списка по одному, а словарь печатает целиком.
3. `print(*l, *d)` передаёт элементы списка и ключи словаря. Поэтому в конце стоят слова `sep` и `end`.
4. `print(*l, **d)` передаёт элементы списка и настройки печати. `sep=','` ставит запятые между элементами, а `end='\n'` заканчивает строку.

### Задание 2 **(2)**
*Напишите функцию* **sublist** для решения следующей задачи.*

*На вход функции поступает список или кортеж и набор номеров позиций.
Функция должна составить и вернуть список из элементов, которые
находятся на этих позициях. Примеры работы приводятся ниже. Работа функции должна строго им соответствовать.*

```
>>> lst = [ 'Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
>>> sublist(lst, 0, 2, 5)
['Anna', 'Clara', 'Flora']
>>> sublist (lst)
[]
>>> sublist(lst, 0, 1, 2, 3, 4, 5)
['Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
```

**Решение**

```python
def sublist(lst, *positions):
    return [lst[i] for i in positions]


lst = ['Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
print(sublist(lst, 0, 2, 5))
print(sublist(lst))
print(sublist(lst, 0, 1, 2, 3, 4, 5))
```

Вывод программы.

```text
['Anna', 'Clara', 'Flora']
[]
['Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
```

`*positions` собирает все переданные позиции в кортеж. Для каждой позиции `i` берём элемент `lst[i]` и добавляем его в новый список. Порядок позиций сохраняется. Если позиций нет, возвращается пустой список. Так же работает и с кортежем вместо списка.

### Задание 3 **(1)**

*Задан список* **lst** *из натуральных чисел*. *Напишите фрагмент
программы, состоящий из одного вызова функции* **max**, *который найдет в этом списке число с максимальным
числом единиц в двоичной записи.* 

*Многоточие надо заменить на лямбда-функцию, использующую фукцию* **bin** *и метод строк* **count**.

*Пример работы приводится ниже.*
```
>>> lst = list(range(6000 ,7000))
>>> ans = max(lst,...)
>>> print(ans)
6143
```

**Решение**

```python
lst = list(range(6000, 7000))
ans = max(lst, key=lambda x: bin(x).count('1'))
print(ans)
```

Вывод программы.

```text
6143
```

`bin(x)` переводит число в строку с двоичной записью. Метод `count('1')` считает единицы в этой строке. Функция `max` сравнивает числа по этому счётчику и возвращает само число.

### Задание 4 **(2)**

*Запишите фрагмент программы, которая упорядочит список слов
по длине, а при равенстве длины - лексикографически. Сортировка
должна состоять из одного вызова метода* **sort**.

*Пример работы приводится ниже.*

```
>>> lst = ['hello', 'hell', 'bye', 'world', 'bybye']
>>> lst.sort (...)
>>> print (lst)
['bye', 'hell', 'babye', 'hello', 'world']
```

**Решение**

```python
lst = ['hello', 'hell', 'bye', 'world', 'bybye']
lst.sort(key=lambda word: (len(word), word))
print(lst)
```

Вывод программы.

```text
['bye', 'hell', 'bybye', 'hello', 'world']
```

`sort` сравнивает пары `(len(word), word)`. Сначала сравниваются длины. Если они одинаковые, сравниваются сами слова по алфавиту.

В исходном списке стоит `bybye`, поэтому после сортировки в выводе остаётся это же слово.

### Задание 5 **(2)**

*Напишите программу для решения следующей задачи.*

*В одной строке через запятую записана последовательность слов. Перед
запятой или после нее могут быть пробелы, сами слова пробелов не
содержат. Программа должна вывести в одной строке через запятую
последовательность чисел, равных длине каждого слова. Например,
для ввода*
```
hello   ,   world ,   and ,   goodbye
```
*программа должна вывести*
```
5, 5, 3, 7
```
*Программа должна быть написана с использованием парадигмы функционального программирования, то есть без использования циклов, присваиваний и т.д. Программа может использовать функции* **input**, **print**, **len**, **map** *и методы строк* **split** и **strip**.

`split(',')` делит строку по запятым. Внутренний `map` применяет `strip` к каждому слову и убирает пробелы по краям. Внешний `map` считает длины. Звёздочка передаёт их в `print` по одному, а `sep=', '` ставит между числами запятую и пробел.

### Задание 6 **(2)**

*Запишите генератор в форме функции, который будет создавать
последовательность по следующему правилу.*

* *Если текущее число x в последовательности четное, то следующее число равно x/2.*
* *Иначе следующее число равно 3x + 1.* 

*Последовательность начинается с заданного числа n и заканчивается единицей.*

*Далее приведен пример работы генератора.*
```
>>> print (*gen(7))
7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```

**Решение**

```python
def gen(n):
    while n != 1:
        yield n
        if n % 2 == 0:
            n //= 2
        else:
            n = 3 * n + 1
    yield 1


print(*gen(7))
```

Каждый `yield` выдаёт одно число. Если `n` чётное, делю его на 2 через `//`, чтобы результат остался целым. Если нечётное, считаю `3*n + 1`. Единицу выдаю в конце.

### Задание 7 **(2)**

*Напишите генератор, который для заданной последовательности*
**seq** *будет задавать последовательность из каждого второго элемента* **seq**.

```
def every_other(seq):
    ...
```
*Ниже приведены примеры использования генератра.*
```
>>> print (*every_other([10, 20, 30, 40, 50]))
10 30 50
>>> print(*every_other(range(10)))
0 2 4 6 8
>>> print(*every_other(iter(range(10))))
0 2 4 6 8
>>> print(sum(every_other(map(int, input().split()))))
2 5 11 3 8
21
```

**Решение**

```python
def every_other(seq):
    it = iter(seq)
    for x in it:
        yield x
        next(it, None)


print(*every_other([10, 20, 30, 40, 50]))
print(*every_other(range(10)))
print(*every_other(iter(range(10))))
print(sum(every_other(map(int, '2 5 11 3 8'.split()))))
```

Получаю итератор и беру из него число `x`. После `yield x` вызов `next(it, None)` пропускает следующий элемент. Если пропускать уже нечего, `next` вернёт `None`. Поэтому подходят список, `range`, итератор и `map`. В последнем примере складываются `2 + 11 + 8 = 21`.

###  Задание 9 **(2)**

*Напишите фрагмент программы, состоящий из одного конструктора списков, который построит двумерный список в виде таблицы умножения размера* 
**n×n**.

*Пример работы приводится ниже.*

```
>>> n = 5
>>> tblmul = [...]
>>> print(*tblmul,sep='\n')
[1, 2, 3, 4, 5]
[2, 4, 6, 8, 10]
[3, 6, 9, 12, 15]
[4, 8, 12, 16, 20]
[5, 10, 15, 20, 25]
```

**Решение**

```python
n = 5
tblmul = [[i * j for j in range(1, n + 1)] for i in range(1, n + 1)]
```

Внешняя часть конструктора создаёт строку для каждого `i` от 1 до `n`. Внутри строки переменная `j` тоже идёт от 1 до `n`, поэтому в ячейке получается `i * j`.

###  Задание 10 **(1)**
*Какие из указанных функций и методов Python соответствуют определению чистых функций?
В случае отрицательного ответа требуется дать пояснение.*

* **file.readline|** — *чтение строки из файла.*
* **len** — *определение длины строки или количества элементов в контейнере.*
* **list.append** — *добавление в список нового элемента.*
* **sum** — *нахождение суммы.*
* **sorted** — *построение сортированного списка.*
* **list.sort** — *сортировка списка.*
* **random.randint** — *генерация случайного целого числа.*
* *Разворот списка.*
```
def rev(x):
    return x[::-1]
```
* *Выбор нескольких элементов из хвоста списка.*
```
tail_len = 3
def tail(x):
    return x[-tail_len:]
```

**Решение**

Чистая функция возвращает результат, который зависит от аргументов, и ничего не меняет снаружи. Для обычных строк, списков и чисел ответы такие.

- `file.readline` — нет. При чтении сдвигается позиция в файле. Следующий вызов может прочитать другую строку.
- `len` — да. Возвращает длину переданного объекта.
- `list.append` — нет. Меняет исходный список.
- `sum` — да, если складываем обычный список чисел. Результат зависит от переданных чисел.
- `sorted` — да, при обычной сортировке списка. Создаёт новый список.
- `list.sort` — нет. Переставляет элементы в исходном списке.
- `random.randint` — нет. При тех же границах ответ может меняться. Он зависит от состояния генератора случайных чисел.
- `rev` — да. Срез создаёт новый список в обратном порядке.
- `tail` — нет. Ответ зависит ещё и от переменной `tail_len` снаружи функции.

###  Задание 11 **(2)**
*Рассмотрите следующую функцию.*
```
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper
```
*Что передается в функцию* **toint**? *Что возвращает эта функция?*
*Что делает функция* **wrapper**?
*Придумайте несколько примеров использования* **toint**.

**Решение**

```python
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper


f = toint(max)
g = toint(lambda x, y: x + y)
print(f('9', '12'))
print(g('7', '5'))
```

В `toint` передаётся функция `fun`. Она возвращает новую функцию `wrapper`. Когда вызываем её, `*args` собирает аргументы, `map(int, args)` превращает их в целые числа, а звёздочка передаёт числа в `fun` по одному. В примере максимум из строк после преобразования равен `12`, а сумма `7` и `5` тоже равна `12`.
